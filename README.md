# سليماني تاكسي

## التشغيل محلياً
```
node server.js
```
ثم افتح http://localhost:3000 — صفحة المدير: http://localhost:3000/admin.html (تحتاج ADMIN_KEY)

## متغيرات البيئة (Environment) على Render
| الاسم | الغرض |
|---|---|
| `ADMIN_KEY` | مفتاح سري طويل لصفحة المدير `/admin.html`. بدونه تُعطَّل الصفحة. |
| `UPSTASH_REDIS_REST_URL` | عنوان قاعدة Upstash Redis (مجانية) لحفظ دائم للرحلات والسائقين |
| `UPSTASH_REDIS_REST_TOKEN` | مفتاح الوصول لها |

بدون Upstash تُحفظ البيانات في ملف يُمسح عند كل إعادة تشغيل على Render المجاني.

## الحسابات
- الراكب بدون حساب.
- السائق يسجّل (هاتف + كلمة سر)، فيبقى «قيد المراجعة» حتى يعتمده المدير من `/admin.html`.
