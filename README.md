# سليماني تاكسي

## التشغيل محلياً
```
node server.js
```
ثم افتح http://localhost:3000

## النشر على الإنترنت (ليستعمله الجميع)
1. ارفع مجلد `slimani-taxi` إلى مستودع GitHub.
2. في https://render.com اختر New ← Blueprint واربطه بالمستودع (يقرأ `render.yaml` تلقائياً).
3. بعد دقائق تحصل على رابط `https://....onrender.com` يعمل على آيفون وأندرويد والحاسوب.

ملاحظات:
- الخطة المجانية تنام بعد فترة خمول وتفقد ملف `data.json` عند كل إعادة تشغيل. للاستعمال الفعلي استعمل خطة مدفوعة مع قرص دائم (`DATA_DIR`) أو قاعدة بيانات.
- تحديد الموقع (GPS) يتطلب HTTPS، وهو متوفر تلقائياً على الاستضافة.

## التثبيت على الهاتف
- آيفون (Safari): مشاركة ⬆️ ← إضافة إلى الشاشة الرئيسية.
- أندرويد (Chrome): زر «تثبيت» يظهر أعلى الصفحة.
